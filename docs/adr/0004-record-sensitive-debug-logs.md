# 在 DEBUG 日志中记录未脱敏的完整诊断数据

当日志级别为 `DEBUG` 时，应用记录未脱敏的接口参数、密码、令牌、Authorization/tenant 请求头、完整配置、响应正文、路径坐标和导入文件正文，以最大化现场复现能力；这部分推翻 ADR 0001 中“配置不得写入日志”的限制，同时继续采用明文本地配置。用户已明确接受任何可读取 `log/` 的用户或进程可取得凭据、重放令牌并读取业务数据，且轮转副本会将这些内容保留最多 30 个历史文件的风险；应用不为日志增加 ACL、加密、脱敏或其他访问控制，DEBUG 日志也不得提交或打入发布包。
