# 使用整弯端点测量代替局部半径统计

每条转弯半径测量以路径中的入弯、出弯样本为稳定输入，使用两个端点位置和区间内连续展开的累计 yaw 求一个整弯等效旋转中心，再计算前轴中心与车辆四角到该中心的五个固定半径。中间样本只用于处理 `±π` 环绕和确定累计旋转量，不再使用距离窗口生成局部瞬时旋转中心，也不输出最小值、中位数或最大值统计。这样自动识别与人工选择共用同一可命名、可持久化的端点模型，结果更适合逐弯道对照；代价是等效圆只概括整个端点区间，不表达区间内部曲率变化。

> 2026-08-27 注：自动识别其后整体移除（见 CHANGELOG「移除」），转弯半径测量全部由用户逐条选点建立；本文所述端点模型与整弯等效旋转中心计算由手动测量继续使用，`turn_radius.py` 的区间识别纯函数保留。
