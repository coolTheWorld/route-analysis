# 威胁模型与安全边界

## 保护对象

- 调度系统用户名、明文密码、租户 ID 和进程内访问令牌。
- 订单、任务、命令、VIN 与路径坐标等业务数据。
- 用户绘制的车道和车辆尺寸参数。
- 调度系统业务状态，必须避免本工具产生任何修改。

## 信任边界

1. 本机用户与 `data/` 目录。
2. 应用进程与配置/导入 JSON。
3. 应用与可配置调度后端之间的 HTTP(S) 连接。
4. 后端返回数据进入领域模型的解析边界。

## 已实施控制

- HTTP 客户端的公开业务能力只有 GET；登录 POST 与业务读取接口明确列举。
- API 根地址仅接受完整 HTTP(S) URL，拒绝内嵌凭据、查询参数和片段。
- 默认启用 TLS 证书校验；关闭只可由本机用户明确设置。
- 访问令牌只存在内存，认证重试最多一次，不写本地。
- 应用无文件日志；用户错误不包含请求头、密码、令牌、完整配置或调用栈。
- 后端路径的数字、有限性、数组/对象结构在边界校验。
- 车道导入限制 schema、单位、serverId/mapId 和数据类型；目标路径仅由十六进制 serverId 与数字 mapId 构成。
- JSON 采用同目录临时文件和原子替换；覆盖前备份。
- `data/`、构建物和缓存均被 Git 忽略。
- UI 网络和分析工作在线程池执行；Qt 对象仅在主线程更新。

## 已接受风险：明文密码

用户明确要求不增加加密，密码按 [ADR 0001](adr/0001-store-credentials-in-plaintext.md) 明文保存在 `data/config.json`。这意味着任何能读取该 Windows 账号文件的进程或用户都能取得密码。

操作要求：

- 仅安装在受信任工作站；不要将整个 `data/` 发送、同步或提交到版本库。
- 使用权限最小化的只读调度账号。
- 通过 Windows ACL 限制发布目录和 `data/` 访问。
- 设备丢失、账号失陷或误传配置后立即更换密码。

## 剩余风险

- 使用明文 HTTP 时，凭据和业务数据可能被网络监听；生产环境应使用 HTTPS。
- 用户可关闭证书校验，会增加中间人攻击风险。
- 恶意或超大后端路径/导入文件可能造成较高内存或 CPU 使用；数据仍经类型和几何校验。
- 步长采样可能漏掉两个样本之间极短的碰撞；降低步长可缓解，但不是解析证明。
- 本工具无法约束后端账号本身的权限；应使用专门的最小权限账号。

## 不在范围内

- 密钥链、DPAPI 或自定义密码加密。
- 服务端 RBAC 配置和审计日志。
- 代码签名、安装程序和自动更新服务。
- 三维坡度、货物外廓和叉齿动态包络。
