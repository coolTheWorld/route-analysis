## 发布与回退

这是便携桌面文件夹发布，不修改服务端、不需要数据库迁移，也没有远程功能开关。建议把 0.3.0 复制到独立目录，以只读调度账号验证一个已知命令的两类路径、自动/手动半径、车道缩放与保存后，再替换操作者版本。

回退步骤：

1. 关闭应用，完整备份当前 `data/` 与 `log/`。
2. 恢复 0.2.1 的完整 `RouteAnalysis/` 程序文件夹。
3. 0.2.1 会忽略新增的 `turn-radius-measurements.json`；该文件可保留供再次升级，也可单独移走。
4. 车道 schema 仍为 2，0.3.0 的平移和统一缩放结果可由 0.2.1 读取；如需恢复缩放前布局，使用对应车道 `.json.bak`。
5. 0.2.1 可能重新写入自己的半径窗口配置，之后再次升级时 0.3.0 会兼容忽略该字段。

发布后首小时人工检查：应用启动、租户登录、订单分页、两类路径点数、自动/手动测量创建与重启恢复、五半径图层、车道长度缩放/整车道拖动、保存/重启和 INFO 日志流。若出现测量错误覆盖、车道几何损坏、持续未捕获异常或关键流程不可用，立即回退程序目录并恢复车道备份。
