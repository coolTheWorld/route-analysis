## 发布与回退

这是便携桌面文件夹发布，不修改服务端、不需要数据库迁移，也没有远程功能开关。建议把 0.4.0 复制到独立目录，以只读调度账号验证一个已知命令的下发/实际点位、完整 JSON、表格/地图双向选择、单来源重试、车辆参数重绘和既有车道/半径功能后，再替换操作者版本。

回退步骤：

1. 关闭应用，完整备份当前 `data/` 与 `log/`。
2. 恢复 0.3.2 的完整 `RouteAnalysis/` 程序文件夹。
3. 0.4.0 未改变配置、车道或半径测量 schema，现有 `data/` 可直接继续使用。

发布后首小时人工检查：应用启动、租户登录、订单分页、两类路径点数、点位/JSON 切换、地图反选、异常点位、实际路径空数据与失败重试、车辆参数同步、车道保存、转弯半径及 INFO 日志流。若出现点位错配、旧命令结果覆盖、持续未捕获异常或关键流程不可用，立即回退程序目录。
