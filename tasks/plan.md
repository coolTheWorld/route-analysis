# 路径通行分析工具实施计划

## 目标

交付一套 Windows x64 桌面应用：通过只读方式查询 Suntae 调度后端的订单、任务、命令和路径，在同一画布中对比下发路径与实际执行路径；以叉车前轴中心和 yaw（弧度）生成车体包络；支持绘制可持久化的直线/三次贝塞尔车道，并通过连续插值判断车辆能否在车道并集中通过。

## 约束

- 技术栈：Python 3.12、PySide6、Requests、Shapely。
- 只向 `route-analysis/` 写入；相邻前后端项目只做事实来源。
- 调度 API 仅允许 GET 查询以及登录所需 POST，绝不调用业务写接口。
- 用户名、密码、租户、API 根地址均存入本地 `data/config.json`；密码按已确认决策明文保存，配置和日志不得进入 Git。
- 路径、车辆、车道使用米和弧度；显示方向变换不得修改原始坐标。
- 每个可独立验证的逻辑切片执行测试先行，并在合并前完成质量审查。

## 里程碑 1：项目骨架与规格

依赖：无。

验收标准：

- 存在完整功能规格、领域词汇、架构决策和 API 契约。
- `pyproject.toml` 固化运行/开发依赖及测试、格式、类型检查配置。
- `.gitignore` 排除虚拟环境、构建物、缓存和全部运行期数据。
- 启动时能够解析统一的数据目录；源码运行使用仓库 `data/`，打包运行使用 EXE 同级 `data/`。

验证：配置解析单元测试；`pytest`、`ruff`、`mypy` 命令可执行。

## 里程碑 2：领域模型、几何与连续扫掠分析

依赖：里程碑 1。

验收标准：

- 车辆矩形以路径点为前轴中心，正 yaw 方向为车头，宽度、中心前距、中心后距均严格大于零。
- yaw 的最短角插值可跨越 `-π/π`，并同时受位置步长和 yaw 步长控制。
- 车道支持开放/闭合、每段直线或三次贝塞尔、每车道宽度、车道默认连接样式及锚点覆盖。
- 尖角连接具有 miter 限制，超限截平；圆角和尖角均可参与多车道并集。
- 缺失 yaw 的点只显示中心点，该点及相邻段不参与车辆包络分析，并报告数据不完整。
- 下发路径和实际路径分别得到绿/黄/红结果、最小净距及位置、首个越界位置和越界数量。

验证：车辆顶点、角度插值、贝塞尔离散、开放端部、闭合车道、连接样式、并集、边界接触、越界、缺 yaw 等单元测试。

## 里程碑 3：只读 API 与本地持久化

依赖：里程碑 1。

验收标准：

- 登录流程先按租户名查询租户 ID，再使用租户请求头登录；令牌过期仅自动重登一次。
- 订单使用 `orderIds` 精确查询和服务端分页；任务、命令、下发路径、实际路径均调用后端现有接口。
- 返回数据在边界处校验，兼容后端标准 `code/data/msg` 包装和命令 JSON 字符串。
- 日志和异常中不出现密码、Authorization、令牌或完整配置。
- 全局车辆参数和 VIN 覆盖、分析参数、地图方向、车道默认宽度均本地保存。
- 车道以“API 服务器 + mapId”隔离；原子保存、前版备份、导入预览、仅替换导入均可测试。

验证：使用假 Session 覆盖请求方法、参数、分页、重登上限和敏感信息；临时目录覆盖持久化、备份和导入验证。

## 里程碑 4：PySide6 单窗口 GUI

依赖：里程碑 2、3。

验收标准：

- 左侧按订单→任务→命令逐级进入，带面包屑、返回、双击和 Enter 操作；订单支持 ID 查询和服务端翻页。
- 右侧为等比例米制画布，显示网格、坐标轴、鼠标坐标；地图方向以弧度旋转整个显示层。
- 下发/实际路径默认同时显示，中心线、车辆、异常点可独立开关，并支持一键单独查看。
- 车道可通过鼠标多点绘制，段可切换直线/贝塞尔，锚点和控制点可拖动及数值编辑；支持开放/闭合、宽度、默认连接及锚点连接覆盖。
- 支持吸附可见路径点；编辑存入逆旋转后的原始坐标。
- 车道修改支持撤销/重做、脏状态、手动保存；切换 mapId/服务器或退出时提示保存。
- 设置面板支持连接、默认车辆、VIN 覆盖、地图方向、分析步长和净距阈值；首次运行阻止进入主功能直至必填车辆尺寸和车道宽度有效。
- 网络和分析工作不阻塞 UI；错误在界面可恢复地呈现。
- 结果面板分别展示两条路径的汇总和定位信息。

验证：Qt 离屏模式组件测试、主窗口冒烟测试、键盘导航和主要可访问名称检查；真实应用启动冒烟。

## 风险控制

- 后端不同部署的数据包装或字段可能略有差异：解析器集中兼容并保留可读错误，禁止 UI 散布后端字段假设。
- 连续扫掠是按可配置步长采样的保守近似，不宣称数学上的解析连续碰撞证明；结果必须展示当前步长。
- 超大路径会带来渲染和分析开销：分析在线程池执行，画布可分别关闭车辆包络层。
- 本地明文密码是用户明确接受的风险：文件保持 Git 忽略，不写日志，文档明确限定于受信任工作站。
